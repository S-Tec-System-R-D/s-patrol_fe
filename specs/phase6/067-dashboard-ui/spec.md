## 🔴 범위 — UI 만 (사용자 결정 2026-10-30)

- **API 를 호출하지 않는다.** 화면에 쓰는 값은 `features/dashboard/mocks/` 의 **고정 데이터**다. MSW 핸들러도 만들지 않는다.
- 타입은 **화면 모양(view model)** 으로 둔다 — 서버 응답 타입이 아니다. 화면을 보고 고친 뒤 이 타입이 **백엔드 요청서의 초안**이 된다(다음 spec).
- 버튼 · 링크는 실제 경로로 간다. 고정 데이터의 `historySeq` · `detailSeq` · `noticeSeq` 는 mock 서버에 있는 값으로 맞춘다(눌렀을 때 빈 화면이 안 나오게).

## User Stories

- US1. 현장관리자가 대시보드에서 **오늘 숫자**(완료 · 미완료 · 시간초과 · 배치 대기)를 한 줄로 본다(누를 수 없다 — 1차 검토 수정).
- US2. **지금 돌고 있는 순찰**을 코스 카드로 본다 — 누가 · 언제 시작 · 기준 대비 경과 · 몇 개 지점까지 · 다음 지점. 문제 있는 코스(시간초과)가 위로 온다. 카드를 누르면 회차 상세로 간다.
- US3. **최근 미완료 · 시간초과**(최근에 생긴 미완료 · 미인증 · 시간초과 지점 기록)와 **공지사항**을 아래에서 본다.
- US4. 진행 중 영역의 빈 상태 · 로딩 · 오류를 본다.

---

## 1. 목적

로그인하면 처음 보는 화면에서 "지금 문제 있는 순찰이 있나" 를 바로 판단하게 한다. 이력(`/patrol/*`)은 끝난 것만 보여서 **지금 상태를 둘 곳이 없었다**(§1-2A) — 그 자리를 대시보드가 맡는다.

## 2. I/O

### 결정 (목업 A안 기준 · 검토 의견 반영 — 사용자 확정 2026-10-30)

| 영역 | 결정 | 목업과 다른 점 |
|---|---|---|
| 머리 | `AppPageHeader` 제목 `대시보드` · 부제 `{사업장명} 순찰 현황` · 오른쪽 `마지막 갱신 HH:mm:ss · 30초마다 자동` + 새로고침 아이콘 버튼 | 제목 크기 · 토큰은 기존 헤더대로 |
| KPI | **4칸** `AppKpiCard inline` — 오늘 완료 · 오늘 미완료 · 시간초과 · 배치 대기(맨 끝). **값이 0 이면 `neutral`**(색 없음). 🔴 **링크 없음**(1차 검토 수정) | `진행 중` 칸 삭제(아래 섹션 개수와 중복) · 목업의 얇은 카드 대신 **기존 KPI 카드** |
| 진행 중 섹션 | 제목 `진행 중인 순찰` + 개수(회색 뱃지 — 이력 패널과 같은 모양) | 파랑 채움 개수 뱃지 → 통일 |
| 카드 정렬 | **시간초과 → 경과 비율(경과/기준) 높은 순** | 목업에 없음 |
| 카드 1줄 | 코스명 · 상태 뱃지(시간초과 `+N분` · 건너뜀 `N`) · ··· · `4/6 지점` | `4 ~ 5 순찰중` 삭제(단계 표시와 중복) |
| 카드 2줄 | 순찰자(교대면 `교대` 뱃지) · `09:00 시작` · `18분 / 30분` + **얇은 시간 막대**(넘으면 `danger`) · `다음: 기계실` | 아바타 삭제 · 시간 막대 추가(B안에서 가져옴) · 다음 지점 문구 |
| 지점 단계 | 지점이 많으면 **다음 줄로**(A안). 색은 **회차 상세 지도 핀과 같은 규칙** — 인증 `success` 채움 · 건너뜀(미인증) `warning` 채움 · 아직 안 감 `muted` 빈 원 · **다음 지점** `point` 점선 원 + 점선 연결 · 번호 표시 | 목업은 완료를 파랑으로 칠함 → 지도와 맞춤 |
| 시간초과 카드 | 테두리 `danger` | 그대로 |
| 하단 2:1 | 좌 `최근 미완료 · 시간초과`(건수 뱃지 없음) · 우 `공지사항`. 좁은 폭(`xl` 미만)은 1열 | 그대로 |
| 이력 행 | 시각(`MM.dd HH:mm`) · 지점 · 코스 · 순찰자 · 뱃지(미완료/미인증 · 시간초과 — `pointCheckBadge` 그대로) · 메모 아이콘. `md` 미만은 코스 · 순찰자 숨김. 행 → `/patrol/points/:detailSeq`. `전체 보기` → `/patrol/points` | 뱃지 색을 기존 이력 화면과 같게 |
| 공지 행 | 제목 · 날짜(`MM.dd`). **핀 아이콘은 고정 공지만**. 행 → `/notice/:noticeSeq`. `전체 보기` → `/notice` | 모든 행 핀 → 고정만 |
| 진행 중 점 | 다음 지점 표시의 깜빡임은 `motion-reduce` 에서 멈춤 | 추가 |

🔴 **색 정정(검토 의견 철회)**: 검토 때 "시간초과는 주황(`warning`)으로 통일" 이라고 했으나 **틀렸다**. 순찰 결과 뱃지의 시간초과는 이미 **`danger`** 다(`design-system.md` 순찰이력 결과 뱃지 ③, SSOT `historyBadge.ts`). 대시보드도 **`danger`** 로 맞춘다 — 목업의 카드 뱃지(빨강)가 맞고, KPI · 이력의 주황이 어긋난 쪽이다.

### 1차 검토 수정 (사용자 2026-10-30)

| 항목 | 수정 | 이유 |
|---|---|---|
| `확인이 필요한 이력` | → **`최근 미완료 · 시간초과`**. 건수 뱃지 삭제 · 시각에 날짜(`MM.dd HH:mm`) | 그 이름이면 **확인하면 사라져야** 하는데, 확인 여부를 담을 DB 컬럼이 없다. 처리할 목록이 아니라 **최근에 일어난 기록**으로 읽히게 한다 |
| 최근 기록 뱃지 | 인증을 마친 행(`완료`)은 결과 뱃지 빼고 **`시간초과` 만** · 뱃지 칸 폭 고정(96px) | `이상없음 + 시간초과` 는 서로 반대 말이다. 이력 화면들의 `이상없음` 은 그대로(정상 행과 섞인 목록이라 필요) |
| 진행 중 카드 배치 | 넓은 폭(`xl`) **2열**. 숫자 스테퍼는 그대로. A안(칸 막대 — 지점 1 = 1칸, 이름은 마우스 올림)을 `?variant=a` 로 비교한 뒤 **버림** | 1열이면 오른쪽이 비었다. 칸 막대는 지점 이름이 바로 안 읽혀 숫자 스테퍼가 낫다(사용자 판단) |
| 지점 단계 모양 | **뱃지형** — 번호 + 지점명을 상태색 뱃지 하나로(바탕 옅은 색 · 번호 원 진한 색), 선 24px 을 뱃지에 바로 붙임. 숫자 스테퍼(번호 원 + 이름, 선 40px)와 `?stepper=pill` 로 비교한 뒤 **선택** · 옵션 삭제 | 선이 이어진 느낌이 강하고 색만으로 어디까지 갔는지 보인다(사용자 판단) |
| KPI 링크 | **삭제** | 숫자를 보는 칸이라 누를 필요가 없다. 시간초과는 갈 목록 필터도 없었다 |
| 지점 단계 숫자 | 세로 중앙 맞춤 — `leading-5` + 모든 원 1px 테두리(채운 원은 투명) | grid 중앙 정렬에서 Pretendard 숫자가 약 1.5px 위로 떴다(4배 캡처로 측정) |

### 화면 상태 보기 (개발 전용)

## 3. 제약

### 기술 제약
- 재사용: `AppPageHeader` · `AppKpiCard`(inline) · `AppBadge` · `AppEmpty` · `AppIconButton` · `pointCheckBadge`(이력 뱃지) · `paths`.
- 새 컴포넌트는 `features/dashboard/components/` 에만 둔다(공용 `App*` 를 새로 만들지 않는다).
- 고정 데이터 시각은 **오늘 날짜 기준으로 만든다**(파일에 날짜를 박으면 다음 날 "오늘" 이 틀어진다).

### 비즈니스 규칙
- 정렬 · 경과 비율 · 다음 지점 · 건너뜀 개수는 **화면이 계산하는 순수 함수**로 둔다 — API 가 붙어도 그대로 쓴다.
  - 다음 지점 = 순서상 첫 미인증 지점 중 **마지막 인증 지점 뒤**의 첫 지점
  - 건너뜀 = 마지막 인증 지점보다 **앞**에 있는 미인증 지점
  - ⚠️ "건너뜀" 은 서버에 없는 개념이다 — 순서대로 찍는 규칙인지 API spec 에서 확인(OQ-067-A)

## 4. 엣지 케이스

공통 규칙 따름. 화면 고유:
- 진행 중 0건 → `AppEmpty` "지금 진행 중인 순찰이 없습니다"(KPI · 하단은 그대로).
- 아직 아무 지점도 안 찍음 → 단계 맨 앞에 `출발` 점 · `0/N 지점` · 다음 = 1번 지점.
- 마지막 지점 직전 → 다음 = 마지막 지점(연결선 없음).
- 지점 12개 이상 → 줄바꿈으로 전부 보인다(가로 스크롤 없음). 390px 에서 가로 넘침 없음.
