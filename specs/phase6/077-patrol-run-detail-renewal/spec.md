## 0. 왜

회차 상세는 7칸 **표** + 오른쪽 `순찰 정보` 카드였다. 시안은 **세로 타임라인**(지점 사이 이동시간 · 특이사항 한 줄 미리보기)과 **요약 4칸**, 오른쪽 **코스 경로 지도**(행 ↔ 핀 서로 강조)로 바꾼다.

---

## 🔴 제약 (실측 · 기존 결정)

1. **이동시간은 서버 값이 아니다** — 인증 시각(`checkDt`)이 있는 행끼리 시간순 차이(`checkGaps`, 036). 시각 없는 지점은 건너뛰고 `(06→08)` 처럼 적는다.
2. **순번은 `orderNo` 그대로**(036 T513 — 서버가 중복 · 결번을 준다. 배열 위치로 다시 매기지 않는다).
3. **사진은 전부 404**(B-40) — 건수는 세고, 펼치면 기존 폴백(`이미지를 불러올 수 없습니다`).
4. 행의 `userName` 은 **null 이 온다** — 행마다 "누가" 를 항상 적을 수 없다.

| 지점 내역 | 7칸 표(`xl`) / 타임라인(`xl` 미만) | **세로 타임라인 하나**(모든 폭): `순찰 시작` → 지점들 → `순찰 종료`. 머리 `n / m 인증` 진행 막대 · `미완료 n` · `기록 모두 펼치기` |

| 진행 중 회차 | — | 마지막 인증 다음 대기 지점에 **`다음 지점`** 뱃지 · 마지막 인증 아래 `N분 경과 · 진행중` |
| 지도 | 왼쪽 위 · 핀 3종 | **오른쪽 열** · 핀 5종(인증 · 미완료 · 미인증 · 다음 · 대기) · **행 ↔ 핀 서로 강조**(누르면 상대가 강조 · 지도는 그 핀으로 이동, 타임라인은 그 행으로 스크롤) · 좌표 없는 지점은 **지도 밑에 이름으로** |
| 교대 이력 | 오른쪽 카드 | 오른쪽 열 **지도 아래**(D1) |

### 결정 (사용자 확인 2026-11-13)

- **D1 교대 이력**: 지도 아래. 머리 부제에 `교대 n`.
- **D2 상태 이름**: 기존 순찰이력 이름(`순찰기록` · `미완료` · `미인증` · `순찰제외` · `진행중` · `대기중`) + 시안의 `다음 지점`. 🔴 **정상(`이상없음`)은 뱃지를 달지 않는다**(076 T1279 와 같다 — 초록 원이 말한다). 대기 지점도 뱃지 없이 오른쪽 끝 `대기` 만(같은 말 두 번 방지).
- **D3 서로 강조**: 이번에 같이 — 행 ↔ 핀 · 요약 `특이사항` → 첫 기록.
