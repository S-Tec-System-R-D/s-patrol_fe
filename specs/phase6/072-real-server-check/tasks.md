# 072-real-server-check tasks

> **경량 작업**(`workflow-protocol.md` §0 — spec.md 없음). 입력: 사용자 결정(2026-11-11) — 서버와 연결된 화면 전체를 실서버에서 한 번 훑는다(`npm run e2e` 는 mock 위라 실서버를 보지 않는다).
> 실행: `npm run dev:real` · IP 주소로 열기. 쓰기 점검은 **테스트용으로 만들고 → 수정하고 → 삭제**한다(원래 데이터를 건드리지 않는다).
> 문제가 나오면 **화면 · 동작 · 증상**을 아래 `## 결과` 에 적고, 고친 건 태스크로 남긴다. 태스크 ID 는 071 T1201 다음부터(T1202~).

## 0. 모든 화면 공통

- [ ] 화면이 오류 없이 열리고, 브라우저 콘솔에 빨간 오류가 없다
- [ ] 새로고침 · 뒤로가기 후에도 검색어 · 필터 · 페이지가 그대로 남는다
- [ ] 값이 없는 칸이 `-` 로 표시된다
- [ ] 좁은 화면(휴대폰 폭)에서 메뉴가 화면 아래 떠 있는 메뉴로 바뀐다

## 1. 로그인 · 공통

- [ ] `/` 에서 현장 계정 로그인 → 대시보드
- [ ] `/admin/login` 에서 본사 계정 3종(시스템관리자 · Master · Manager) 각각 로그인
- [ ] 근무자 계정 차단 · 본사 계정의 현장 로그인 차단
- [ ] 사업장 전환 → 대시보드로 돌아오고 데이터가 바뀐다
- [ ] 로그아웃 확인 창 → 로그인 화면

## 2. 현장 사이트

**대시보드** — 실시간 · 교대 표시는 070 T1199 에서 확인 완료

- [ ] 오늘 숫자 · 최근 미완료/시간초과 · 공지 3건이 실제 데이터와 맞다

**순찰코스** `/zones`

- [ ] 목록 검색 · 필터 · 정렬, 상세 열기
- [ ] 코스 추가 → 지점 편성 · 순서 끌어서 바꾸기 · 구간시간 → 저장 → 다시 열었을 때 그대로
- [ ] 사용 여부 스위치 껐다 켜기(확인 창 포함)
- [ ] 상세 지도 · 지점 순서 · 요약 지표 · 최근 순찰 기록
- [ ] 테스트 코스 삭제

**순찰지점** `/points`

- [ ] 목록 · 상세 열기, 지도 · 순찰 인증 기록
- [ ] 지점 추가 → 수정(설명 비워 저장 포함) → 인증수단 전환 → QR 내려받기
- [ ] 테스트 지점 삭제(버튼 문구 "삭제")

**순찰이력** `/patrol/zones` · `/patrol/points`

- [ ] 코스 · 지점 탭 목록, 기간 · 결과 필터, 페이지 이동
- [ ] 회차 상세 — 인증 내역 · 지도 · 교대 이력 · 메모 · 사진
- [ ] 지점 인증 상세 — 인증 정보 · 지도 · 최근 인증

**근무자** `/users`

- [ ] 목록 검색 · 상세(최근 순찰 기록 · 배치 이력 · 더보기)
- [ ] 테스트 근무자 추가(비밀번호 확인 칸 포함) → 수정 → 삭제

**배치관리** `/deployments`

- [ ] 탭 3개 · 대기 숫자 뱃지 · 전출/전입 인원
- [ ] 배치 요청 승인 · 거부, 복귀 요청 처리(대기 건이 있을 때만)
- [ ] 이력 탭 이름 검색

**공지사항** `/notice`

- [ ] 목록 · 상세
- [ ] 테스트 공지 작성 → 수정 → 삭제

## 3. 본사 사이트

**사업장/관리그룹** `/admin/locations`

- [ ] 관리그룹 트리, 본부 · 지사 추가 → 이름 변경 → 삭제(테스트용)
- [ ] 사업장 목록(본부 · 지사 열) · 검색
- [ ] 사업장 추가(본부 → 지사 → 상위 사업장) → 수정 → 삭제
- [ ] 사업장 상세 — 담당 관리자 목록, 비상연락망(요일별 담당자 추가 → 해제)

**관리자** `/admin/admins`

- [ ] 목록 · 상세
- [ ] 테스트 관리자 추가 → 정보 수정 → 비밀번호 재설정 → 삭제
- [ ] Master · Manager 로그인 시 관리할 수 없는 계정의 버튼이 막혀 있다

## 4. 권한 차단

- [ ] 현장 계정으로 `/admin/*` → 403 화면
- [ ] 본사 계정으로 현장 주소 → 본사 첫 화면
