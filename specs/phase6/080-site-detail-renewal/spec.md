### 결정 (사용자 확인 2026-11-16)

- **D1 타임아웃 = 숫자만** — 시안의 `1회 무응답 허용`은 쓰지 않는다. 단위 미확인(OQ-044-B).
- **D2 하위 사업장 = 이름 + 링크** — 시안대로(개수 대신).
- **D3 모바일 비상연락망 = 요일별 카드(A안)** — 시안의 이어 붙인 7줄 목록은 요일 구분이 약하다(사용자). 레퍼런스(Apple HIG inset grouped · PagerDuty 빈 구간 표시) 조사 후 A안. 연필(편집 창) 대신 카드 안에서 바로 추가 · 해제.

### 수정 (사용자 확인 2026-11-16, 첫 구현 뒤)

- **D4 헬스체크 = 값 먼저 + 24시간 막대(B안)** — 사용 시간(+ 예외 한 줄) · 체크 주기 · 타임아웃 · 반복을 크게, 그 아래 **얇은 하루 막대**(사용 구간 포인트색 · 예외는 빈 틈 · 자정 넘김 두 구간 · 눈금 0 · 6 · 12 · 18 · 24시)는 보조. 레퍼런스 = CCTV 녹화 일정의 하루 막대(Reolink · Hikvision · Home Assistant 일정 — 설정 화면이라 우리는 **읽기 전용**). "공대 같지 않게"(사용자) — 칸 테두리 없이 옅은 바탕 한 덩어리 · 눈금 5개만.
- **D5 꺼지면 [수정] · `설정 수정` 숨김** — 켜는 길은 토글 하나(값이 비었으면 토글이 설정 창을 연다). 꺼짐은 `미사용` 글자 · 흐린 값 · 안내 문장이 말한다.

- ~~**D6 예외 시간 입력 = 구간 한 칸**~~ → 되돌림(사용자: 한 칸으로 묶으면 UX 가 나쁘다 · 시작 / 종료 칸은 나눈다). 남긴 것: 시작 칸 `~` 종료 칸 + 삭제 · 점선 `+ 예외 시간 추가` · 머리 옆 `이 시간에는 확인하지 않습니다`.
- **D8 시각 입력 부품 `AppTimeInput`(새로)** — 요청의 뜻은 **시계 선택 창 · 키보드 입력칸 자체의 디자인**이었다. 브라우저 `type="time"` 은 시계 창 · `오전/오후` 칸을 꾸밀 수 없어 글자 칸 + 팝오버로 만든다. **24시간 `HH:mm`**(숫자만 치면 `1230` → `12:30` · 떠날 때 `9` → `09:00`) · 시계 버튼 → **시 · 분 두 열 목록**(분 5분 단위 + 지금 값 · 열면 고른 값으로 스크롤 · 분을 고르면 닫힘). 설정 창의 시각 칸 4개 모두(사용 시작 · 종료 포함). 형식 검사는 스키마(`00:00 ~ 23:59`).
- **D7 막대 눈금 글자 = 시각 자리 가운데** — `justify-between` 은 글자 폭 때문에 6 · 12 · 18 이 눈금에서 밀렸다(사용자). `24` 뒤 `시` 는 숫자 밖에 띄워 붙인다.

- **D9 카드 제목 아이콘 삭제** — 사업장 상세 4장(기본정보 · 담당 관리자 · 헬스체크 · 비상연락망) + 근무자 상세 `기본정보`. 다른 상세 화면 카드 제목은 글자만이고 시안도 아이콘이 없다(사용자 결정 2026-11-16 — 모두 빼기). 요약 숫자 칸(`AppKpiCard`)의 아이콘은 지표 표시라 둔다.

- **D10 비상연락망 머리 `담당자 N명` 삭제**(사용자) — 요일 칸이 사람을 보여 준다.

### 구현 메모

- 비상연락망은 **한 DOM** 을 폭마다 다르게 그린다 — 두 벌이면 같은 버튼 접근 이름이 겹친다. 7칸 주간 표는 **`2xl`(1536)** 부터 — 1280 캡처에서 칸이 90px 남짓이라 연락처가 잘렸다. 그 아래(1280 포함)는 요일별 카드.
- 빈 요일 버튼의 접근 이름은 `월요일 담당자 추가`(채워진 요일의 `+ 추가` 와 같다) — 보이는 글자만 `담당자 지정`.
- `SiteDeleteDialog` 는 트리거 없이 `open` 으로 연다(머리 `⋯`).
