## User Stories

- US1. 사업장을 여럿 가진 현장관리자가 **로그아웃 없이** 레일(PC) · 하단 메뉴(모바일)의 전환 버튼으로 사업장을 바꾸고, 현장 홈(`/zones`)에서 **새 사업장 데이터**를 본다.
- US2. 사업장이 1개뿐인 현장관리자 · 본사 계정에게는 전환 버튼이 **보이지 않는다**.

---

## 1. 목적

지금은 사업장을 바꾸려면 로그아웃 → 재로그인 → 사업장 선택을 거쳐야 한다. 로그인 안에 있던 선택 단계를 로그인 뒤에도 열 수 있게 한다.

---

## 2. I/O

### 결정 (사용자 확정 2026-10-29)

| 항목 | 결정 |
|---|---|
| 버튼 위치 · 형태 | 레일 = 로그아웃 **바로 위** · floating nav = 로그아웃 **옆** 아이콘 버튼. 누르면 **모달**로 사업장 목록. 툴팁에 현재 사업장명 |
| 1개 소속 계정 | 버튼 **숨김** — 선택지 2개 이상일 때만 |
| 전환 뒤 이동 | 어디서 바꾸든 **항상 현장 홈**(`paths.service.zones` — 로그인 진입과 같은 곳) |
| 전환 중 오버레이 | 사업장을 고른 순간부터 **화면 전체를 덮어 아무것도 클릭되지 않게** 한다("사업장 전환 중"). **홈의 첫 조회가 끝나면**(성공 · 실패 모두) 걷는다 — 실패는 화면의 기존 에러 표시에 맡긴다 |

### Input
- `GET Login/W/sign/UserSiteSelect` — 이미 실측된 조회 API(`api-spec.md` §2-2). 선택지 변환은 기존 `toSiteOptions`(루트 + children) 그대로.
- 현재 사업장: `getSiteSeq()` · `getSiteName()`(`lib/auth/site.ts`).

### Output
- 모달: 선택지 목록 + **현재 사업장 표시**. 현재 사업장을 고르면 아무것도 하지 않고 닫는다.
- 다른 사업장 선택 → 모달 닫고 **전환 중 오버레이** → `setSite(siteSeq, siteName)` → 홈 이동 → 홈 첫 조회 끝 → 오버레이 해제.

### 저장/외부 효과
- localStorage `auth.siteSeq` · `auth.siteName` 교체. 서버 쓰기 없음(선택 확정 API 없음 — 021).

## 3. 제약

### 기술 제약
- 🔴 **`getSiteSeq()` 는 반응형이 아니다** — 렌더 때 localStorage 를 읽을 뿐이다. 이미 홈(`/zones`)에 있을 때 바꾸면 **같은 주소로 이동**이라 다시 그려지지 않을 수 있다. 전환 뒤 현장 영역 전체가 새 `siteSeq` 로 다시 그려지게 한다(방법은 WF-2 에서).
- 조회 키에 `siteSeq` 가 들어 있다(points · courses · course-history 규약) — 캐시 비우기는 키 규약이 없는 쿼리만 확인한다.
- 레일 · floating nav 는 **본사와 공용**이다(`spec 043` T743). `UserSiteSelect` 호출은 **`ServiceLayout` 이 한다** — 본사 토큰으로 부르면 403(상호 배타, `api-spec.md` §2-2).
- `SiteSelectStep`(021)을 재사용한다. 로그인 카드 쪽 겉모습은 바뀌지 않는다.
- 목록 조회 실패 · 로딩 중이면 버튼을 그리지 않는다(뱃지와 같은 방침 — 숫자 · 목록을 지어내지 않는다).
- 전환 중 오버레이는 프로젝트에 **기존 컴포넌트가 없다**(모달 오버레이뿐) — 새로 만든다. 레일 · floating nav(`z-40`) · 모달(`z-50`)까지 덮고, 키보드 포커스도 뒤로 가지 않게 한다. 조회가 끝나지 않는 경우에 대비해 **걷히지 않는 오버레이가 남지 않게** 한다(방법은 WF-2 에서).

### 비즈니스 규칙
- 선택지 규칙은 로그인과 **같다**(루트 포함 · 루트 먼저 · 계층 표시 없음).
- 사업장 전환은 **현장관리자만**(본사는 사업장을 고르지 않는다 — `spec 043` · `999`).

---

## 4. 엣지 케이스

공통 규칙 따름(B급). 단 하나: 저장된 `siteSeq` 가 선택지에 없으면(소속이 바뀜 등) 모달에 현재 표시가 없을 뿐 고를 수 있게 둔다 — 강제 로그아웃 같은 새 규칙은 만들지 않는다.
