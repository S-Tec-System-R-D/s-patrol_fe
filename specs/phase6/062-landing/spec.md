## User Stories

- US1. 현장관리자가 `s-patrol.co.kr/` 로 들어오면 **xl 이상에서 왼쪽 로그인 · 오른쪽 서비스 소개 슬라이드**를 한 화면에서 보고, 그 자리에서 로그인(+ 사업장 선택)해 현장 홈으로 간다.
- US2. 소개 슬라이드는 자동으로 넘어가고, ← → · 점 표시로 직접 넘기거나 일시정지할 수 있다.

## 1. 목적

지금 `/` 는 라우트가 없어 404 다. 도메인 첫 화면을 **로그인 겸 서비스 소개**로 채운다.

---

## 2. I/O

### 결정 (사용자 확정 2026-10-29)

| 항목 | 결정 |
|---|---|
| 범위 | **`/` 만 새로 만든다.** `/login` · `/admin/login` 화면은 건드리지 않는다(겉모습 · 동작 그대로) |
| 로그인 | **실제 로그인** — 지금 로그인 처리(`code` 분기 · 근무자 차단 · 사업장 선택 단계 · 착지)를 그대로 쓴다. `LoginForm` 의 바깥 틀(화면 가운데 카드)과 안쪽 내용을 나눠 안쪽만 랜딩에 넣는다 |
| 슬라이드 | **임시 문구 + 레일 색(`--rail`) 배경 + 아이콘.** 기능 4개(순찰이력 · 코스/지점 · 배치관리 · 공지사항) 제목 + 한 줄 설명. 나중에 화면 캡쳐로 바꾸기 쉽게 데이터 배열 하나로 둔다 |
| 절차 | 짧은 spec · 정식 사이클 |

### 목업 → 우리 화면

| 목업 | 랜딩 |
|---|---|
| 회색 배경 가운데 큰 흰 카드 · 좌우 반 | 그대로 |
| 소셜 로그인 · 구분선 · Forgot password | **뺀다**(사번 로그인만 · 비밀번호 찾기 만들지 않음 — 058) |
| 이메일 · 비밀번호 · 로그인 버튼 | 지금 로그인 폼 내용(사번 · 비밀번호 · 로그인) |
| 오른쪽 어두운 패널(카드 안쪽 여백 · 둥근 모서리) | `--rail` 배경 · 아이콘 · 기능 제목 · 한 줄 설명 |
| 점 표시 · ← → | 그대로 + **일시정지 버튼** |
| — | xl 미만: 오른쪽 패널 숨김 → **xl 카드의 왼쪽 반 그대로**(폭 최대 550 · 높이 최소 640 · 좁으면 화면 폭) — 사용자 결정 2026-10-30. 전에는 `/login` 과 같은 작은 카드였다 |

### Input
- 로그인 · 사업장 선택: 기존 API(`Login/W/Login` · `UserSiteSelect`) — 새 호출 없음.

### Output
- 라우트 `/`(공개 · 가드 없음 — `/login` 과 같은 자리).
- 로그인 성공 → 지금과 같은 착지(현장 `/zones` · 본사 `/admin/locations`).

## 3. 제약

### 기술 제약
- `LoginForm` 분리는 **`/login` 겉모습 · 동작이 바뀌지 않는 범위**에서만 — 기존 로그인 테스트(`LoginPage.test.tsx` 등) · e2e 로그인 흐름이 그대로 통과해야 한다.
- 자동재생: 일정 간격(5초)으로 넘긴다. 🔴 접근성 — **일시정지 버튼**(WCAG 2.2.2) · 마우스를 올리거나 포커스가 들어오면 멈춤 · `prefers-reduced-motion` 이면 자동재생 안 함.
- 새 패키지 없음(슬라이더 라이브러리 쓰지 않는다 — 4장 · 페이드/이동 하나).
- 로그인 상태로 `/` 에 와도 **그대로 보인다**(`/login` 과 같음 — 리다이렉트 규칙을 새로 만들지 않는다).

### 비즈니스 규칙
- 본사 로그인 링크는 노출하지 않는다(`flow.md` §0). 본사 계정이 여기서 로그인하면 지금처럼 응답 `code` 가 본사로 보낸다.
- 슬라이드 문구는 **임시**다 — 확정 문구는 OQ.
