## User Stories

- US1. 현장관리자가 근무자 상세에서 **최근 순찰 기록을 날짜별로** 보고, 인증을 했는지(✓/✕)와 봐야 할 예외(시간초과·메모)를 한눈에 가른다.
- US2. 현장관리자가 근무자 상세에서 **배치 이력을 타임라인으로** 보고, 지금 배치 중인지 · 며칠째인지 · 언제 복귀했는지를 읽고, 이력이 길면 [더보기]로 이어 본다.

---

## 1. 목적

근무자 상세 우측의 두 카드(최근 순찰 기록 · 배치 이력)가 **같은 행 모양**(`[날짜] [이름] [뱃지]`)이라 구분이 안 되고 밋밋했다(사용자 지적 2026-10-26). 행에 장식을 붙이지 않고 **카드마다 데이터 성격에 맞는 모양**을 준다 — 순찰 기록은 시각순 묶음, 배치 이력은 기간 타임라인.

---

## 2. I/O

### Input
- 최근 순찰 기록: `GetPointHistory?siteSeq&userSeq&pageNumber=1&pageSize=8` — **변경 없음**
- 배치 이력: `GetAssignmentHistory?userSeq&pageNumber=1&pageSize={5·10·15…}` — 🔴 `status` 를 보내지 않는다(필터 제거)
- 근무자 상세 `siteName`(= **소속지**, 실측) — 배치 이력 행의 출발지

### Output
- 화면만 바뀐다. 라우트 · 링크(`행 → 지점 인증 상세`, `전체 기록 → 순찰이력 목록`)는 그대로.

---

## 3. 제약

### 결정 표 (사용자 결정 2026-10-26)

| # | 요소 | 결정 |
|---|---|---|
| 1 | 순찰 기록 묶음 | 날짜 머리(`10월 26일 (월)` + 오늘이면 `오늘`) 아래 행. 🔴 **머리에 `· n건` 을 적지 않는다** — 8건에서 잘려 마지막 날짜가 실제보다 적게 보인다 |
| 2 | 순찰 기록 결과 | 왼쪽 **✓(완료) / ✕(미완료)** 아이콘만. 오른쪽 결과 글자 뱃지(`이상없음`·`순찰기록`·`미완료`)는 없앤다. 아이콘의 `aria-label`·툴팁은 기존 5종 문구(`pointCheckBadge`) |
| 3 | 순찰 기록 오른쪽 | **예외만** — `시간초과`(overTimeYn) · `메모`(hasMemo, 완료·미완료 공통) + 인증 방식(`authMethodName`, 빈 문자열이면 생략). 정상 행은 비운다 |
| 4 | 배치 이력 모양 | 세로 타임라인 점 — **배치중만 채운 점**(point), 나머지는 빈 원. 진행 막대는 **두지 않는다**(비율로 읽혀 옆 글자와 모순) |
| 5 | 배치 이력 출발지 | `{근무자 소속지} → {siteName}`. 소속지는 바뀌지 않는다는 전제(사용자 2026-10-26). 소속지가 `null` 이면 `→` 앞을 생략 |
| 6 | 배치 이력 오른쪽 | 배치중 `n일째` + 종료일 있으면 `· n일 남음` / 배치예정 `n일 후 시작` / 복귀완료 `n일`(시작~복귀). 🔴 **시작일 = 1일째**(시안 `7일째`·`46일` 과 같은 셈) |
| 7 | 배치 이력 기간 | 기존 `formatPeriod`(`2026-10-20 ~ 미정`) 유지. 복귀완료는 `· {completeDt} 복귀` 를 덧붙인다 — 🔴 **OQ-042-E 를 닫는다**(`completeDt` 를 쓴다, 사용자 2026-10-26) |
| 8 | 배치 이력 페이징 | 상태 필터 · 페이지네이션 제거 → **[더보기]**(5건씩 이어 붙임). 다 보이면 버튼을 숨긴다 |

### 기술 제약
- 더보기는 `useInfiniteQuery` 를 들이지 않는다 — **`pageSize` 를 5씩 키운다**(이력이 짧다: 진행 중 배치는 1인 1건, `api-spec.md` 배치 동작). 키를 바꾸는 동안 이전 목록을 유지해 깜빡이지 않게 한다(`placeholderData`). 서버 상한 100.
- 상태 뱃지는 `AssignmentStatusBadge` 그대로, 카드 안 버튼은 `AppLinkButton`(048 규칙).
- 결과 문구의 SSOT 는 `pointCheckBadge` · `overtimeBadge` — 아이콘 판정도 여기서 읽는다(사본 금지).

### 비즈니스 규칙
- 순찰 기록은 **선택 사업장 한정**, 배치 이력은 **전체 사업장** — 캡션으로 구분(기존 유지).
