> 위험도: **B**(조회 화면 개편 — 새 엔드포인트 · 쓰기 없음).
> 시안: `docs/ui-mock/현장/개선안/순찰이력/지점 인증 상세 개선안.html` — 특이사항 있음 / 없음 2장(사용자 결정 2026-11-13).
> 관련: `spec 037`(지점 인증 상세) · `050`(순찰 상세와 같은 골격) · `076`(지점 상세) · `077`(순찰 상세 — 건너뜀 · 예외만 뱃지)

## 0. 왜

이 화면의 고유 정보는 **그 인증 1건에 남긴 순찰 기록(메모 · 사진)** 이다. 시안은 그것을 맨 위로 올리고, 기록이 없으면 지도가 본문을 차지한다. 아래 `이 지점의 최근 인증` 카드(그래프 + 8건)는 지점 상세(076)가 이미 하는 일이라 **한 줄 요약 + 지점 상세 링크**로 줄인다.

---

## 🔴 제약 (실측)

1. **회차 번호(`historySeq`)가 없다**(037 US4 백엔드 회신 대기) — 시안의 `순찰 회차` 링크(`11.07 10:50 회차`)는 **만들 수 없다** → 행을 뺀다(D1).
2. **`pauseTime` 의 의미가 확정되지 않았다**(OQ-037-A) — 시안의 `이전 지점에서 N분 이동` 으로 이름 붙일 근거가 없고, 회차를 몰라 직접 계산할 수도 없다 → **행을 뺀다**(D2).
3. **메모에 작성자 · 작성 시각이 없다**(실측) — 시안의 `11.07 10:54 작성` 은 만들 수 없다 → 순찰자 이름만(D4).

## 범위

| 영역 | 지금 | 바꾼 뒤 |
|---|---|---|
| 머리 | 지점명 · 결과/초과 뱃지 · 부제 문구 | 지점명 · **결과 뱃지(인증 / 건너뜀 / 미인증) + `특이사항` + `시간초과`** · 부제 **`순찰자 · MM.dd (요일) HH:mm · 인증수단`** · 오른쪽 **`지점 상세`** |
| 특이사항 있음 | 지도 → 순찰 기록 → 최근 인증 / 오른쪽 인증 정보 | **왼쪽 `순찰 기록`** → 최근 14일 한 줄 / **오른쪽 지도 + 인증 정보** |
| 특이사항 없음 | (같음) | **왼쪽 지도** → 최근 14일 한 줄 / 오른쪽 인증 정보. `남긴 기록이 없습니다` 카드는 그리지 않는다 |

| 최근 인증 | 카드(14일 점등 · 곡선 · 최근 8건) | **한 줄**: `이 지점 최근 14일 · 인증 n · 건너뜀 n · 특이사항 n` + `지점 상세에서 보기 ›` |

### 결정 (사용자 확인 2026-11-13)

- **D1 순찰 회차 링크**: 뺀다 — 회차 번호가 생기면(037 US4) 추가.
- **D2 구간 / 이전 지점에서**: **아예 뺀다**.
- **D3 머리 뱃지**: 결과 하나(완료 → `인증` — 한 건만 보는 상세라 정상도 적는다 · 미완료 → `건너뜀`/`미인증`) + 메모 있으면 `특이사항` + 시간초과면 `시간초과`. 목록의 `순찰기록` 대신 결과와 특이사항을 나눠 적는다(시안).
- **D4 메모 작성 시각**: 없다 — 순찰자 이름만.
