## 0. Carry-over

- 078: 결과는 머리 뱃지에서만, 칸에는 **비어 있는 이유**를 적는다(D7). 지점 상태 3은 시각 있음 = `건너뜀` · 없음 = `미인증`(077).
- 지금 근무자 상세의 순찰 기록은 `GetPointHistory?userSeq`(지점 인증 1건 = 1행, 최근 8건)다 — **회차 번호가 없어**(037 US4) 회차로 묶을 수 없다.

## 1. 왜

시안의 기록은 **코스 회차 1건 = 1행**이고, 행을 펼치면 그 회차의 지점별 인증 · 특이사항 · 교대가 보인다. 회차로 묶어야 아코디언 · 인증 n/m · 교대 표시가 성립한다 → 기록 출처를 **`GetCourseHistory`(회차 목록)** 로 바꾼다.

---

## 🔴 제약 (실측 · 사용자 확인)

1. **`GetCourseHistory` 는 `userSeq` 로 거를 수 없다** — `userName` 만 있고 **부분 일치(%like%)** 다(사용자 확인 2026-11-16). → 이름으로 받고 행의 `userList[].userSeq` 에 **이 근무자가 있는 회차만** 남긴다(동명 · 이름 포함 제거).
2. **`userList` 는 지점을 처리한 사람만** 나온다(api-spec §5-1-D 2026-11-04). 교대받고 하나도 처리하지 않은 회차는 **빠진다** — 서버 구조상 한계로 둔다.
3. **목록에 지점별 인증 여부가 없다**(`pointCount` · `checkedCount` 만) → 접힌 행의 인증 막대는 **비율**, 지점별은 **펼칠 때** `GetCourseHistoryCheckDetails` · `GetCourseHistoryHandOvers`(그 회차만).
4. **목록에 코스 기준 시간이 없다** → `시간초과` 표시만(초과 분 · 기준 없음, D3).
5. `pointCount` 가 순찰제외를 빼고 센 값인지 미확인(api-spec 15) → 인증 %는 **두 수의 비**로만 적고 색을 입히지 않는다.
6. `siteSeq` 필수 — **선택한 사업장의 기록만**(지금과 같다).

### 결정 (사용자 확인 2026-11-16)

- **D1 회차 수 숫자 없음**: 날짜 머리 `n회` · 막대 위 숫자를 빼고 날짜 · 막대 높이로만. 요약 칸 `순찰 n회`(14일 합계)는 둔다.
- **D2 용어**: 회차 = `미완료 포함`, 펼친 지점 = `건너뜀` / `미인증`(077). 시안의 `누락` 은 쓰지 않는다.
- **D3 시간초과**: `시간초과` 표시만 — 초과 분 · 기준 시간은 적지 않는다.
- **D4 근무자 거르기**: `userName` 으로 받고 `userList` 의 `userSeq` 로 다시 거른다(제약 1 · 2).

### 수정 (사용자 확인 2026-11-16, 첫 구현 뒤)

- **D5 날짜 머리 예외 요약 삭제**: `미완료 포함 n · 시간초과 n` 을 뺀다 — 아래 회차 줄 표시와 겹친다. 날짜 · `오늘` 만.
- **D6 교대 문장은 한 번**: 접힌 줄 `교대` 1 + 펼친 지점 목록 점선 1. 펼친 한 줄 요약의 교대 문장(`n번부터 교대받음`)은 뺀다 — 점선을 놓을 지점이 없는 교대(`nextOrderNo` 없음 · 목록 밖)만 요약에 남긴다.
- **D8 지점 `건너뜀` → `미인증` 하나로(전 화면)**: 서버는 건너뛴 지점(뒤 지점을 먼저 찍은 순간 `3` + 시각)과 종료로 남은 지점(`3` · 시각 없음)을 **같은 상태**로 둔다(백엔드 확인 2026-11-16) — 077 부터 시각 유무로 가른 `건너뜀` 을 없앤다. `pointCheckBadge(status, hasMemo)`(시각 인자 삭제) · 순찰 상세 타임라인 머리 `미인증 n` · 순번 원 · 지도 핀 4종(빈 원 `미인증` 삭제) · 지점 상세 요약 · 막대 범례 · 지점 이력 결과 필터 · 대시보드 단계 · 카드 뱃지. 대시보드 내부 식별자 `skipped` 는 그대로. 지점 상태 `2 순찰제외` 는 설계 변경으로 미사용(백엔드 확인) — 매핑은 남긴다.
- **D9 배치 이력 기간**: 복귀완료는 `시작 ~ 종료 · 종료 일시 복귀`(날짜 두 번) → `시작 ~ 복귀 일시`(`2025-12-01 ~ 2026-01-15 18:00`). 상태는 뱃지 `복귀완료` 가 말한다. ⚠️ 복귀 시각(`completeDt` = 승인 시각)이 예정 종료일과 다른 날이면 예정 종료일은 보이지 않는다.
- **D10 회차 `미완료 포함` → `미인증`**: `미완료` 는 서버 이름이다 — 요약 칸 · 범례 · 툴팁 · 펼친 요약(`미인증 n`)까지 회차 · 지점 모두 `미인증`(D2 · D8 이어서).
- **D11 회차 상태 = `진행중` / `완료` · 미인증은 지점에만(전 화면)**: 미인증 지점이 있어도 순찰 자체는 끝났다 — 지점 상태가 회차 상태를 침범하지 않는다. `courseResultBadge` 서버 `2` → `완료`(success) · 순찰코스 이력 결과 필터 `전체 · 진행중 · 완료`(완료 = 서버 1만, 사용자 결정) · 코스관리 상세 기록 표 상태(공통 뱃지) + `시간초과` · `누락` 칸 삭제 · 회차 모달 지점 `미인증`(주황) · 요약 `미인증 n` · 평균 칸 `시간초과 n/m` · 소요 막대 시간초과 빨강 · 근무자 요약 `미인증 지점` 수 · 막대 정상 / 시간초과 · 대시보드 오늘 숫자 `완료`(1 + 2) · `미인증 지점`(오늘 끝난 회차 빠진 지점 합) · 최근 기록 `미인증 · 시간초과`(빠진 지점 있는 회차 — 서버 완료도 포함). 색: 미인증 주황 · 시간초과 빨강. ⚠️ **백엔드 수정 대기(B-69)**: 결과 `완료` 필터는 서버 `1` 만 거른다(`eventType` 값 하나) — 화면에서 완료로 보이는 서버 `2` 회차가 빠진다. 코스 `status` 를 코스 자체 상태(진행중 / 완료)로만 저장 · 필터해 달라고 요청한다 — 반영되면 코드 수정 없이 맞는다.
- **D7 접힌 줄 정렬**: 있다 없다 하는 `교대` · `시간초과` 를 인증 막대 **왼쪽**으로 — 오른쪽 막대 · `인증 n/m`(폭 고정) · 소요가 줄마다 세로로 맞는다.
