| 영역 | 지금 | 바꾼 뒤 |
|---|---|---|
| 머리 | 빨간 `삭제` 만 | `수정` 버튼 + `⋯` 메뉴(삭제) |
| 지점 순서 + 순찰 동선 | 카드 2개 | **순찰 경로** 카드 하나 — 왼쪽 지도(좌표 없으면 다이어그램) · 오른쪽 지점 목록 + 지점별 인증률 막대 · `편성 편집` |

| 최근 순찰 기록 | 전부 · 인증 글자 · 기준 초과 열 | **10건** + `전체 기록 N건 보기`(순찰이력 코스 필터) · 인증 막대 · **누락 열** · 초과는 상태 옆 뱃지 · **행 → 회차 상세 모달** |
| 회차 상세 모달 | 없음 | 요약(근무자 · 소요 · 인증) + 지점별 인증 시각 / 누락 · 이전/다음 회차 · `상세 보기`(순찰이력 상세 페이지) |

### 결정
- **회차 모달 ↔ 이력 상세 페이지**: 모달에 `상세 보기` 링크를 둔다 — 사진 · 메모 · 교대는 페이지에서 본다.
- **스위치 → 글자**: 바꾸기는 수정 모달에서. 확인 모달(`CourseToggleDialog`)은 없앤다 — 모달 저장이 곧 확인이다. 효과 문구(`앱 코스 목록에 노출`)는 수정 모달 스위치 옆에 둔다.
- **근무자별**: 교대 회차는 양쪽에 센다(시안 문구 그대로). 근무자 없는 회차는 `근무자 없음` 행.
- 🔴 **OQ-074-A 지점별 인증률 — API 연동 안 함**(사용자 결정 2026-11-12). 막대 · `n/m회` 는 **화면만** 그리고 값은 지점 순번으로 만든 자리표시 값이다. 실데이터와 맞지 않는다. 연동 방법(지점 수만큼 `GetPointHistory` / 서버 집계 요청)은 미정.
