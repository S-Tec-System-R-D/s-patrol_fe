# 076-point-detail-renewal spec

> 위험도: **B**(조회 화면 개편 — 새 엔드포인트 · 새 쓰기 없음. 지점 삭제 · 수정은 기존 그대로).
> 시안: `docs/ui-mock/현장/개선안/지점관리/코스지점 상세 개선안.html` — **개선 B(속성 패널 + 활동 타임라인)** (사용자 결정 2026-11-13).
> 관련: `spec 027`(지점 상세 페이지) · `029`(QR 내려받기 · 인증수단 전환) · `031`(14일 요약) · `074`(코스 상세 개편 — 같은 머리 규칙)

---

## 0. 왜

코스 상세(074)를 시안대로 바꿨다. 지점 상세도 같은 시안 묶음의 개선 B 로 맞춘다 — "이 지점이 무엇인가"(속성)와 "언제 찍혔나"(활동)를 좌우로 가른다.

---

## 🔴 제약 (실측 · 기존 결정)

1. **지점 기록에 회차 번호(`historySeq`)가 없다**(`PointHistoryRow` · `PointHistoryDetail` — `spec 037` US4 백엔드 회신 대기). 시안의 **"행 클릭 → 회차 상세 모달"은 만들 수 없다** → 행은 **지점 인증 상세**(`/patrol/points/:detailSeq`)로 간다.
2. **QR 은 화면에 그리지 않는다**(`spec 029`, 보안 — 화면을 찍어 현장 밖에서 인증할 수 있다). 시안은 NFC 지점만 그렸다 → QR 지점은 TAG ID 자리에 **기존 `QR 코드 내려받기` 버튼**을 둔다(미리보기 없음).
3. **지점 기록 상태**: 완료(4) · 미완료(3) · 순찰제외(2) · 진행 중(1) · 대기(0). 미완료 행도 `checkDt` 를 갖지만 **인증 시각이 아니다**(OQ-15).

| 좁은 폭(`xl` 미만) | 1단 | 1단 · 속성 패널이 먼저 |

### 결정

- **D1 행 이동**: 지점 인증 상세(`/patrol/points/:detailSeq`) — 회차 모달은 `historySeq` 가 생기면(037 US4).
- **D2 상태 표시**: 완료 → `인증`(초록 체크, 시각 표시) · 미완료 → `누락`(주황, 시각 `—`) · 순찰제외 → `제외`(회색) · 진행 중 · 대기 → `진행 중`(회색). 막대는 **인증 · 누락만** 센다.
- **D3 `수정` 위치**: 패널의 `기본정보` 제목 줄(코스 상세 074 와 같은 규칙 — 고치는 값이 있는 카드에). 시안은 머리에 뒀다.
- **D4 지점명 행 삭제**: 시안대로 — 패널 위가 바로 머리(이름)다(027 의 "캡처용 지점명 행" 결정을 뒤집는다).
- **D5 지도**: 등록 좌표 핀 1개 · 스크롤 줌 끔. 좌표가 없거나 범위 밖이면 빗금 칸에 `등록된 좌표가 없습니다`.
