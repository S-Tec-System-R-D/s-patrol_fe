## 0. Carry-over (직전 spec 핸드오프)

- 082(개발 전용 시뮬레이터)의 이월 4건 — 실시간 로그 다듬기(T1427 · OQ-082-B) · 생체확인 작업(OQ-082-A) · 브라우저 미확인 항목(OQ-082-D) · "배치 거절됨" 표시(OQ-082-E) — 은 **모두 시뮬레이터 범위**라 이 spec 에서 다루지 않는다. 082 후속으로 그대로 남긴다.
- 🔴 시뮬레이터(`/dev/simulator`)는 자기 글꼴 · 다크 테마를 따로 쓴다(`simulator.css`). **이 spec 의 변경이 시뮬레이터의 색 · 틀을 바꾸지 않아야 한다.** 한글 글꼴만 앱을 따라간다 — 시뮬레이터의 한글은 예비 글꼴(Pretendard)로 그려지고 있었고, Pretendard 를 빼면서 Noto Sans KR 로 바꿨다(사용자 결정 2026-11-20).

## 🔴 범위

- **되돌아올 지점**: 태그 `design-before-renewal-2026-11`(커밋 `22971d9`). 개편 작업은 브랜치 `design-renewal-2026-11` 에서 한다.
- **바꾸는 것**: 글꼴 · 색 · 줄바꿈 / 바깥 틀(사이드바 · 본문 카드 · 위 줄) / 상태 표시 / 표 · 버튼 · 검색 · 필터 · 페이지 이동 · 빈 상태 · 모달 틀 같은 **공용 구성 요소**.
- **바꾸지 않는 것**: 데이터 흐름 · 라우트 · 권한 · 문구 · 화면별 구성(영역 배치 · 칸). 화면별 구성은 084 · 085 에서 바꾼다.
- 🔴 **틀과 공용 구성 요소는 현장 · 본사가 같이 쓴다**(`RailSidebar` · `App*`). 그래서 이 spec 이 끝나면 **본사 화면도 글꼴 · 색 · 틀 · 공용 구성 요소가 함께 바뀐다**(사용자 결정: 본사도 동일하게 변경). 본사 화면 고유의 배치(관리그룹 단 · 사업장 상세)는 085 다.
- 🔴 **이 spec 이 끝난 직후의 화면은 중간 상태다** — 틀과 부품은 새 모양, 화면 안의 카드 배치는 옛 모양. 084 가 끝나야 목업과 같아진다.

## User Stories

- US1. 현장관리자가 어느 화면에서나 **같은 글꼴 · 색 · 크기 단계**로 읽는다. 한글 윗부분이 흐리게 보이지 않고, 문장이 단어 중간에서 끊기지 않는다.
- US2. 현장관리자가 **이름이 적힌 사이드바**에서 메뉴를 고르고(아이콘에 마우스를 올려야 이름이 뜨던 것을 없앤다), 지금 화면의 위치를 위 줄에서 읽는다.
- US3. 현장관리자가 상태(완료 · 미완료 · 진행 · 시간초과 등)를 **아이콘 + 글자**로 구분한다. 색에만 기대지 않는다.
- US4. 현장관리자가 목록 화면에서 **같은 모양의 검색 · 필터 · 표 · 페이지 이동**을 쓴다.
- US5. 현장관리자가 데이터가 없을 때 **왜 비었는지**(처음부터 없음 / 조건에 맞는 것 없음 / 불러오지 못함)를 구분해서 본다.

## 1. 목적

지금 화면은 68px 아이콘 사이드바 + 카드 중심 배치이고, 화면마다 글자 크기 · 버튼 모양 · 상태 표시가 조금씩 다르다. 현장관리자가 종일 띄워 두거나 순찰 중 잠깐 확인하는 화면이므로 **선 · 여백 중심의 차분한 틀**과 **한 벌의 공용 부품**으로 정리한다. 화면별 개편(084 · 085)이 이 위에 얹힌다.

## 2. I/O

값의 기준은 `디자인-규칙.md` 다. 여기에는 **무엇을 어디에 적용하는지**만 적는다.

### 2-1. 글꼴 · 색 · 줄바꿈

| 항목 | 지금 | 바꿀 것 |
|---|---|---|
| 글꼴 | Pretendard(`index.css` 가 `pretendard` 패키지를 불러온다) | **Noto Sans KR**. `pretendard` 패키지와 불러오는 줄을 없앤다 |
| 줄바꿈 | 기본값 | 전역 `word-break: keep-all` |
| 크기 단계 | 토큰 10종(`--text-page-title` 22px 등) · 본문 12.5px | 화면 제목 20 / 영역 제목 15(600) / 내용 13 / 보조 12 / 11. 기존 토큰 이름은 유지하고 값을 맞춘다(쓰는 곳이 많다) |
| 색 | slate 토큰 · `--point #3b82f6` | 파랑 `#2563eb` · 설명용 회색 `#64748b`(아이콘 회색도 같은 값). 빨강 = 문제, 초록 = 정상 완료, 파랑 = 진행 · 누를 수 있음 · 순서. **주황은 쓰지 않는다** |

- 🔴 **글꼴은 앱에 묶어 싣는다**(패키지로 설치해 우리 서버에서 내려 준다 — 지금 Pretendard 와 같은 방식). 목업은 구글 웹폰트 주소를 썼지만, 서버를 IDC 에 배포하므로(사용자 2026-11-20) 바깥 주소에 기대지 않는다. 쓸 패키지와 싣는 굵기(400 · 500 · 600 · 700)는 태스크에서 용량을 재고 정한다.
- 🔴 주황(`warning`) 토큰을 쓰는 곳을 전부 찾아 빨강 · 회색 · 파랑 중 하나로 옮긴다. 화면별 판단이 필요한 곳은 084 로 넘긴다.

### 2-2. 바깥 틀

| 항목 | 지금 | 바꿀 것 |
|---|---|---|
| 사이드바(`xl` 이상) | 68px 어두운 아이콘 레일 · 이름은 툴팁 | **224px 밝은 사이드바** — 로고 · (현장) 사업장 선택 칸 · 메뉴(아이콘 + 이름) · 아래 사용자 이름 · 권한 |
| 메뉴 묶음 | 없음(flat 6개) | 현장: 묶음 제목 `현황`(대시보드 · 순찰이력) / `관리`(코스/지점 · 근무자 · 배치관리 · 공지사항). 메뉴 6개와 순서는 그대로. 본사: 사업장 · 관리자(묶음 제목 없음 · 사업장 선택 칸 없음) |
| 처리할 건수 | 레일 뱃지 | 메뉴 줄 오른쪽 **파란 알약**(배치관리) |
| 본문 | 페이지 배경 위에 카드들 | **본문 카드 한 장**(사이드바 옆 · 둥근 모서리). 맨 위 줄에 지금 위치(상세 화면은 `부모 › 지금`) |
| 기준 크기 | — | 1920×911 에서 목업과 같게 |

- `xl` 미만은 **지금 동작 유지** — 아래 `FloatingNav` · 한 열. 색 · 글꼴만 따라간다(OQ-083-B).
- 사업장 전환(`spec 061`) · 로그아웃 · `<Outlet key={siteSeq}>` 동작은 그대로다. 놓이는 자리만 바뀐다.
- 🔴 본사 틀(`AdminLayout`)은 배치 대기 조회를 부르지 않는 규칙을 그대로 지킨다.

### 2-3. 상태 표시

- **아이콘 + 글자**. 색은 아이콘에만 주고 글자는 본문색(빨강만 글자도 빨강).
- 완료 · 인증 = 초록 체크 / 미완료 · 미인증 = 회색 빼기 원 / 진행 = 파란 고리 / 시간초과 = 빨간 시계 / 반려 = X 원 / 근무 중 = 점 원.
- **분류 · 설정 값**(권한 · 인증수단 · 교대)은 아이콘 없이 글자만.
- 지금의 색 바탕 뱃지(`AppBadge`)를 이 모양으로 바꾼다. 쓰는 곳이 넓으므로 **종류(variant) 이름은 유지하고 모양만** 바꾸는 것을 먼저 검토한다.

### 2-4. 공용 구성 요소

| 구성 요소 | 바꿀 것 |
|---|---|
| 버튼 · 검색 칸 · 필터 | 높이 30px. 주 버튼은 파란 바탕(화면에 하나). 필터는 아이콘 + 값 + 꺾쇠(이름을 값 앞에 붙이지 않는다 — 사용자 결정 2026-11-20), 걸려 있으면 파란 테두리 |
| 화면 제목 오른쪽 버튼 | 테두리 없이 옅은 회색 채움. `삭제` 는 옅은 빨강 채움 + 빨간 글자 |
| 표 | 줄 46px · 카드 밖 · 줄 전체가 누르는 대상. 고른 줄은 옅은 회색 바탕 |
| 페이지 이동 | 1280px 이상 `« ‹ 번호 5개 › »`(지금 페이지 가운데) · 그보다 좁으면 `‹ ›` 만 · 왼쪽 `현재 / 전체 페이지`. 지금의 `1 … 4 5 6 … 20` 계산(`pageItems`)을 바꾼다 |
| 빈 상태 | 흰 타일 아이콘 → 제목 → 설명. 넓은 자리에만 타일, 한 영역 안은 회색 글자 한 줄. 겹친 카드 그림 · 순찰 경로 그림은 없앤다 |
| 숫자 칸 | 낮은 칸(60px)은 코스 상세 3칸만 남고 나머지는 상자 없는 한 줄 숫자 — 모양만 여기서 만들고 **화면 적용은 084** |
| 모달 틀 | 어두운 막 + 흰 상자(모서리 12px). 입력 폼 = 가로 전체 폭 버튼(지금 유지) / 확인 창 = 아이콘 · 제목 · 설명 가운데 + 버튼 반반 / 편집 창 = 오른쪽 아래 작은 버튼 |
| 차트 | shadcn 차트 모양(Recharts) — 가로 격자만 · 축 선 없음 · 둥근 막대 · 카드 툴팁. 공용 조각만 만들고 **화면 적용은 084** |

## 3. 제약 (기술 + 비즈니스)

- 🔴 **동작을 바꾸지 않는다** — 라우트 · 가드 · 조회 · URL 쿼리 · 접근 이름(`aria-label` · 역할)은 그대로. 테스트가 접근 이름으로 요소를 찾으므로 이름이 바뀌면 그 이유를 태스크에 적는다.
- 🔴 **색에만 기대지 않는다** — 상태는 아이콘 모양 + 글자가 함께 간다. 대비는 `디자인-규칙.md` 의 대비 표를 지킨다(설명용 회색 4.76 등).
- 🔴 **다크 모드는 지금 동작 유지**(OQ-083-C) — 다크 토큰은 남기고 새 색에 맞춰 값만 따라간다. 다크 목업은 없다.
- 공용 구성 요소의 **이름 · props 는 가능한 한 유지**한다. 화면 코드가 넓게 쓰고 있어, 모양만 바꾸면 084 의 변경이 줄어든다.
- `cva` variants 는 인접 `.variants.ts` 에 둔다(`CLAUDE.md` B4).
- 같은 파일을 연달아 저장하지 않는다(사용자의 개발 서버가 뒤 변경을 놓친다) · `prettier --write` 금지.
- 기존 문서(`design-system.md` · `layout.md` · `components.md`)는 **084 의 마지막 태스크에서 한꺼번에** 새 규칙으로 고친다. 이 spec 에서는 뒤집히는 결정이 있는 절에 "083 에서 바뀜" 표시만 남긴다.

## 4. 엣지 케이스

| 경우 | 처리 |
|---|---|
| 글꼴이 늦게 들어온다 | 그동안 시스템 글꼴로 보인다. 들어온 뒤에도 배치가 크게 흔들리지 않게 한다 |
| 사업장이 하나뿐인 현장관리자 | 사업장 선택 칸은 이름만 보이고 눌리지 않는다(지금 규칙 — 선택지 2개 이상일 때만 전환) |
| 사업장 · 사용자 이름이 길다 | 사이드바 안에서 한 줄 말줄임 |
| 배치 대기 건수가 0 | 알약을 그리지 않는다 |
| 페이지가 5쪽보다 적다 | 있는 만큼만 번호를 그린다(1쪽이면 `1`) |
| 첫 쪽 · 마지막 쪽 | 갈 수 없는 화살표는 흐리게 · 눌리지 않는다 |
| `xl` 미만 | 사이드바 대신 아래 `FloatingNav` · 페이지 이동은 `‹ ›` |
| 움직임 줄이기 설정 | 이 spec 에는 움직임이 없다(대시보드 움직임은 084) |
| 시뮬레이터(`/dev/simulator`) | 색 · 틀은 바뀌지 않는다. 한글 글꼴만 Noto Sans KR 로 따라간다 |
