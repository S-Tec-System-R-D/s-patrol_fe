   ⚠️ 꺾쇠는 내용 안에서 우측 끝에 둔다(셸을 고치지 않는다).
4. 🔴 **미사용 톤다운이 타일에도 걸려야 한다** — `rowClassName` 은 카드 **바깥**에 붙으므로,
   타일 배경이 그 위에서 그대로 밝으면 **미사용인데 멀쩡해 보인다**.
5. **미실측 인증수단 코드(9·10 외)는 중립 타일** — 추측 아이콘을 만들지 않는다(A1).

### 🔴 구현 중 겪은 함정 — 뱃지 색이 지워졌다

`AppBadge` 는 `cn(badgeVariants(variant), className)` 로 병합한다. 크기를 줄이려고
**폰트 크기 토큰 `text-label` 을 `className` 으로 넘겼더니**, `tailwind-merge` 가 그것을
**글자색으로 분류해** variant 의 색(`text-success-foreground`)을 **지워 버렸다** — 뱃지
글자가 전부 검정이 됐다(사용자가 발견).

- **원인**: 커스텀 폰트 크기 토큰은 `tailwind-merge` 의 기본 사전에 없어 `text-{color}` 로 읽힌다.
- **수정**: 임의값 `text-[10.5px]` — **폰트 크기로 인식**되어 충돌하지 않는다.
  🔴 `spec 028`(편성 모달)이 같은 자리에서 이미 임의값을 썼는데, 034 에서 "토큰이 낫다" 며
  바꾸다 밟았다. **그 선택에는 이유가 있었다.**
- **재발 방지**: 테스트 2건 — "크기를 줄여도 variant 색이 남아 있다".
