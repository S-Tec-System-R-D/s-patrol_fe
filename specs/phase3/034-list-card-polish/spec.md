## User Stories

- **US1.** 현장관리자가 좁은 폭에서 목록을 훑을 때, **행의 시작점이 고정**돼 있어 눈이
  좌측 축을 따라 내려간다 — 지금은 카드마다 글자부터 시작해 리듬이 없다.
- **US2.** 지점 목록에서 **QR/NFC를 색과 아이콘으로 먼저 알아본다**(글자를 읽기 전에).

---

## 1. 목적

`spec 030` 이 만든 카드 2벌(`CourseCard`·`PointCard`)을 **목업 A안**과 **031 어휘**에 맞춘다.

030 은 **구조**(무엇을 남기고 무엇을 접을지)를 정했고 **시각은 손대지 않았다**. 031 이
카드 어휘(아이콘 칩·라벨·뱃지·보조 줄 토큰)를 세웠으므로, 이제 목록 카드가 그것을 따라간다.

## 3. 제약

### 목업 A안의 골격

```
[타일]  A동 순찰코스  [사용] [교대 허용]              >
        📍 지점 3개  │  ⏱ 45분
```

| 요소 | 규칙 |
|---|---|
| **타일 아이콘** | 좌측 고정. 🔴 **행의 시작점을 고정하는 장치**다 — 이름 길이가 달라도 눈이 좌측 축을 따라 내려간다 |
| 이름 + 뱃지 | 1단. 이름(굵게) + 사용여부 + 유형 뱃지 |
| 지표 줄 | 2단. 아이콘 + 값을 `│` 로 나눠 한 줄 |
| **꺾쇠(`>`)** | 우측 끝. "들어갈 수 있다" 를 말한다 |
| 미사용 | 카드 전체 톤다운(**030 의 `rowClassName` 이 이미 한다**) |

### 🔴 타일 색 — 031 의 "칩은 중립" 과 **다르게 간다**

| | KPI 4칸(031) | 목록 카드(034) |
|---|---|---|
| 배치 | **가로로 나란히** | **세로로 쌓임** |
| 색이 하는 일 | 칸끼리 **경쟁** | 행의 **시작점 고정 + 유형 구분** |
| 결론 | 중립 | **색을 쓴다** |

"칸마다 다른 색 금지" 는 **나란한 칸들** 이야기였다. 목록에서 타일 색은 **유형 식별**이라
근거가 있다 — 특히 지점은 **QR/NFC 로 갈린다**(코스는 유형이 하나라 전부 같은 색).

### 비즈니스 규칙

1. **지점 타일은 인증수단으로 갈린다** — QR `QrCodeIcon`(point 계열) / NFC `NfcIcon`
   (success 계열). 🔴 **`lucide` 의 `qr-code`·`nfc` 를 쓴다**(사용자 지정 2026-10-14).
   ⚠️ 미실측 코드(9·10 외)는 **중립 타일**이다 — 추측 아이콘을 만들지 않는다(A1).
2. 🔴 **뱃지도 유지한다**(사용자 결정 2026-10-14). 목업 설명은 "타일 색으로 구분해 배지를
   줄였다" 였지만 **둘 다 둔다** — 색만으로 의미를 전하지 않는 접근성 규약
   (`design-system.md`)을 지키면서, 타일은 **훑어보기**를, 뱃지는 **확인**을 맡는다.
3. 🔴 **"최근 순찰" 줄을 뺀다**(사용자 결정 2026-10-14) — 목업 3단 중 마지막 줄.
   ⚠️ 테이블(`xl` 이상)에는 **컬럼으로 남는다**. 좁은 폭에서는 **고르는 데 쓰는 값**만
   남기는 030 의 원칙(§3 규칙 5)에 맞춘 선택이다.
4. **코스 타일은 `RouteIcon` 하나** — 유형이 갈리지 않으므로 색도 하나다.
5. 031 토큰을 그대로 쓴다: 타일 `size-* rounded-md`, 이름은 `text-body font-semibold`,
   지표 줄은 `text-caption text-muted-foreground`. **새 토큰을 만들지 않는다.**

## 4. 엣지 케이스

| 상황 | 처리 |
|---|---|
| 이름이 길다 | **한 줄 말줄임**. 뱃지는 밀리지 않는다(`shrink-0`) |
| 미사용 | 030 의 `rowClassName` 이 카드 전체를 톤다운한다 — **타일도 함께 가라앉아야** 한다 |
| 인증수단 미실측 코드 | 타일 **중립** + 뱃지 없음(030 에서 이미 그렇게 한다) |
| 지점 수·소요시간이 0 | **그대로 보여준다**(`지점 0개`) — 경고하지 않는다(023 규칙 12) |

## 5. 완료 조건 (DoD)

- [ ] 1. 코스·지점 카드가 **타일 + 이름/뱃지 + 지표 줄 + 꺾쇠** 골격을 쓴다
- [ ] 2. 🔴 **지점 타일이 인증수단으로 갈린다**(QR `QrCodeIcon` / NFC `NfcIcon`),
      미실측 코드는 **중립**
- [ ] 3. 🔴 **뱃지를 유지**했다(타일 + 뱃지 둘 다, 사용자 결정) — 색만으로 의미를 전하지 않는다
- [ ] 4. 🔴 **"최근 순찰" 줄을 뺐다**. 테이블 컬럼에는 **그대로 남아 있다**
- [ ] 5. 미사용 카드에서 **타일도 함께 톤다운**된다
- [ ] 6. 🔴 **`xl` 이상 테이블이 무변화** — 캡쳐로 확인
- [ ] 7. **새 토큰을 만들지 않았다** — 031 어휘 안에서 끝냈다
- [ ] 8. `npm run verify` 0 errors + `npm run test` green (857 → 유지/증가)
- [ ] 9. 브라우저 확인 — 좁은 폭에서 코스·지점 카드 3항목 이상
