## 제약 (구현 중 지킬 것)

1. 🔴 **서버 요청을 늘리지 않는다.** 좌표는 `GetCourseDetail` 이 이미 준다.
2. 🔴 **키가 없어도 나머지 화면이 멀쩡해야 한다** — 팀원·CI 가 키 없이 개발한다.
3. 🔴 **범위 밖 좌표를 지도에 넘기지 않는다**(B-33) — 핀이 날아가고 `fitBounds` 가
   지구 반대편까지 벌어진다.
4. 🔴 **다이어그램 카드를 없애지 않는다** — 좌표가 없는 코스에서는 그것이 **유일한 경로 표현**이다.
5. **`leaflet` CSS 를 전역에 흘리지 않는다** — 지도 영역 밖 스타일이 바뀌면 안 된다(DoD #8).
6. **지도 인스턴스를 정리한다**(`map.remove()`) — 라우트를 오가며 쌓이면 메모리와 이벤트가 샌다.
