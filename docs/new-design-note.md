# S-Patrol 리디자인 — UI 디자인 노트

## 배경 / 참조

- 기존 프로토타입: `S-Patrol.html`(React+JSX: `shell.jsx`, `users.jsx`, `zones.jsx`, `history.jsx` 등) — 화면 데이터·인터랙션 로직의 원본. 이번 리디자인은 **UI만 교체**, 데이터/문구/기능 범위는 그대로 가져옴.
- 방향성: 기존 UI가 "장난감 같다(toy-like)"는 피드백 → Notion / Linear / Vercel 계열의 미니멀하고 밀도 높은 SaaS 스타일로 전환.
- 결과물은 전부 **정적 HTML 목업**(클릭 인터랙션·모달 없음), 최종적으로 Canva 이미지로 각 화면을 내보내는 것이 목표.

## 디자인 시스템

**컬러 (OKLCH 기반)**

- 배경 `--bg` / 카드 `--surface`(흰색) / 테두리 `--border`, `--border-soft`
- 텍스트 3단계: `--text`(본문), `--text-2`(보조), `--text-3`(희미한 라벨/타임스탬프)
- 액센트(블루 계열) `--accent` / `--accent-bg` / `--accent-dark` — 선택 상태, 주요 배지, 프라이머리 버튼
- 상태색: `--success`(초록, 완료/활성), `--danger`(빨강, 미완료/삭제), `--amber`(주의/대기), 각각 연한 `-bg` 페어
- 다크 사이드바 전용 `--rail`, `--rail-2`

**타이포그래피**

- Pretendard, 본문 13px, 테이블 12.5px, 라벨 10.5~11px uppercase — Linear/Notion 밀도를 의도적으로 재현(웹 슬라이드/문서 대비 훨씬 작은 스케일)
- 페이지 타이틀 17px, 섹션 타이틀 14~15.5px

**공통 셸 구조**

- 좌측 68px 다크 아이콘 레일(sticky, 풀하이트) — 상단 로고, nav 아이콘 4개(활성 상태는 밝은 배경+좌측 액센트 바), 하단 프로필 아바타(온라인 dot)
- GNB/브레드크럼 없음 — 페이지 제목 + 설명 한 줄 + 액션 버튼만 있는 얇은 헤더
- 본문은 `.col-main` 안에 탭 → 필터 칩 → `.body-row`(테이블 카드 + 우측 상세 패널) 순서
- 상세 패널은 테이블과 **동일한 레벨의 카드**(테두리+radius)로 감싸고 `position:sticky`로 스크롤 추종 — 초기 버전은 패널이 풀블리드였다가 "따로 노는 느낌" 피드백으로 카드화
- 페이지는 고정 높이/overflow:hidden을 쓰지 않고 자연스럽게 스크롤되는 구조(뷰포트 제한 없는 실제 웹앱 환경 반영)
- 테이블 카드 하단엔 페이지당 행 수 선택 + prev/next 페이지네이션 footer

## 화면별 구성

**1. 순찰이력** (`S-Patrol Redesign - History (Modern).html`)

- 탭: 코스 순찰이력 / 지점 순찰이력 (JS로 전환)
- 코스 탭: 테이블(코스명·시작·종료·결과, 30건 예시) + 우측 상세 패널(순찰 정보 + 타임라인 카드 리스트, 8지점 예시, 특이사항/미완료 항목은 펼쳐진 노트 표시)
- 지점 탭: 전체 폭 테이블(순찰일자·시간·코스·지점·인증·순찰자·결과·기록건수), 상세 패널 없이 기록 건수를 버튼으로 표시(모달은 미구현)

**2. 코스/지점** (`S-Patrol Redesign - Zones (Route Map, 8pts).html`)

- 탭: 코스 / 지점
- 코스 탭: 좌측 코스 목록 + 우측에 **경로 다이어그램 카드**(체크포인트를 zigzag 레이아웃으로 배치, 점선 연결선 + 구간별 소요시간 라벨, 4개 지점마다 줄바꿈)와 그 아래 **드래그 가능한 지점 순서 리스트 카드**(그립 핸들, 잠금/수정/삭제 아이콘 버튼)를 별도 카드로 분리 — S-Patrol만의 공간적 시각 정체성을 위해 추가한 요소
- 지점 탭: 좌측 지점 목록(검색+정사각형 추가 버튼) + 우측 상세 카드(기본정보·소속 코스·인증수단, QR 다운로드 또는 NFC TAG ID, 수정/삭제)

**3. 근무자** (`S-Patrol Redesign - Users (Modern).html`)

- 순찰이력과 동일한 테이블+우측 상세 패널 구조로 통일
- 테이블: 이름(아바타)·연락처·소속 사업장(배치중 배지 포함)·근무 상태·사용자 상태·등록일
- 상세 패널: 기본정보 + 배치 변경 이력(참고 표시) + 액션(비밀번호/수정/근무자 삭제) — **배치변경 버튼은 제거**(배치는 근무자 앱에서 요청하는 방식으로 워크플로 변경됨)
- 소속 사업장 값은 부서명("정문경비" 등)이 아닌 실제 현장 건물명("강동 테크노타워" 등)으로 통일

**4. 배치관리** (`S-Patrol Redesign - Deployment (Modern).html`)

- 배치는 자주 발생하지 않는 이벤트라 단순 테이블 대신 **대시보드형**으로 구성
- 상단 요약 카드 3개: 배치 나간 인원 / 배치 온 인원 / 대기중인 배치요청
- **배치 요청 목록**을 이력보다 위에 배치(확인 용이성 우선) — 카드형 row + 승인/거부 버튼
- 배치 이력은 탭(배치 나간 이력 / 배치 온 이력)으로 분리 — 두 방향의 표시 컬럼(경로·사유·기간·상태)이 달라 필터 토글 대신 탭 사용
- 배치 경로는 실제 사업장명 기준으로 표기(예: "강동 테크노타워 → 강서 스퀘어타워")
