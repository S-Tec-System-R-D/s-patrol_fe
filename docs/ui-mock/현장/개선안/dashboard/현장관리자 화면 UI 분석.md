# 현장관리자 화면 UI 분석 및 개선 방향

범위: UI 피드백만 다룸. 데이터 정합성·서버 로직, 캡처 도구로 인한 사이드바 끊김은 제외.
전제: 배치관리 화면은 mock 데이터, 나머지는 실제 데이터 캡처. "배치 대기"는 배치 요청(들어오는 요청)과 복귀 요청(나갔다가 복귀를 요청)을 모두 대기 상태로 묶은 명칭으로 유지.

---

## 1. 전체 공통

### 1-1. 넓은 화면에서 열이 흩어짐 (화면 › 위치)
- 대시보드 › 최근 종료된 순찰: 코스명은 왼쪽, 작성자·인증 수·소요시간·상태는 오른쪽 끝. 사이 약 1200px 공백인데 작성자는 "현장 관리자 테스..."로 잘림.
  → 시간 · 코스명 · 작성자를 왼쪽에 붙이고, 인증 수·상태만 오른쪽.
- 대시보드 › 최근 미완료·시간초과: 지점명과 코스명 사이 약 700px 공백. 근무자 "현장 근무..." 잘림.
  → 같은 방식으로 왼쪽에 묶기.
- 대시보드 › KPI 칸: "오늘 완료"와 "3건" 사이 약 280px.
  → 숫자를 라벨 바로 아래로.
- 근무자 목록 표: 이름 열 약 550px, › 가 등록일에서 250px 이상 떨어짐.
  → 이름 열 폭 축소, › 제거하고 행 전체 클릭.
- 코스/지점 › 지점 탭 표: 사용여부 배지와 › 사이 약 250px.
  → 근무자 목록과 동일 처리.
- 공지사항 목록·배치관리 표는 내용이 차 있어 유지.

### 1-2. 아바타 글자
- 이름 앞 두 글자를 써서 "현장", "현장", "근무"처럼 반복됨. → 이름 끝 두 글자 사용.

### 1-3. 정상 상태 강조 과다
- 코스/지점 › 지점 탭 › 사용여부: 16행 모두 초록 "사용". → 비워두고 "미사용"만 회색 배지.
- 코스/지점 › 지점 탭 › 인증수단: NFC 배지가 초록이라 "사용"과 같은 색. → NFC·QR 모두 회색 바탕, 글자로만 구분.
- 대시보드 › 최근 종료된 순찰 › 상태: 모든 행이 초록 "완료". → 배지 제거, 예외만 표시.
- 대시보드 › KPI: 0건이 굵은 검정. → 0은 회색.

### 1-4. 보조 텍스트 대비
- 상단 설명 문구, 날짜 등 작은 회색 글씨 대비 부족. → 한 단계 진하게.

### 1-5. 삭제 버튼
- 근무자 상세, 공지 상세에서 삭제가 수정과 같은 크기의 빨간 버튼. → 더보기(⋯) 메뉴로 이동하거나 외곽선 버튼으로 낮춤.

## 2. 화면별

### 대시보드
- 순서: 이미 끝난 순찰이 처리할 일보다 위. → KPI → 진행 중 → 처리 필요 → 최근 기록.
- 진행 중 순찰 카드: 진행률이 오른쪽 끝에 떨어짐, 시간 막대가 짧음, "교대"가 칩 위에 떠 있음, "다음:" 문구가 칩과 중복, 카드 오른쪽 절반 빈 공간.
- 최근 미완료: 지점마다 한 줄이라 순찰 1건이 여러 줄로 쪼개짐. → 순찰 단위로 묶고 놓친 지점은 그 안에 이름으로.
- 배치 대기: 메뉴 이동 없이 대시보드에서 승인/반려 가능하게.

### 코스/지점
- 소속 코스 수가 파란 숫자라 링크처럼 보임. → 링크로 쓸지 일반 텍스트로 둘지 결정 필요.

### 근무자 목록·상세
- 원소속 값이 없으면 "-"로 열 전체가 비어 보임. → 값 있을 때만 표시 또는 근무 상태 열과 병합.
- 상세: 이름 옆 배지와 기본정보에 근무 상태 중복.
- 순찰 기록 모든 행에 "미배정 코스" 반복. → 코스 없으면 생략.

### 공지사항
- 본문 한 줄이 화면 끝까지 늘어남. → 본문 최대 폭 약 720px.
- 제목 옆 확성기 아이콘 박스는 정보 없음. → 제거.

### 배치관리
- 요청마다 "N일 대기" 경과일 표시.
- 오른쪽 위 전출/전입 인원 숫자를 해당 탭 배지로 이동.

## 3. 대시보드 개선안에 반영한 내용 (대시보드 개선안.html)

### 레이아웃
- xl(1280px 이상): 68px 사이드 레일 + 본문 2열(왼쪽 순찰, 오른쪽 440px 배치 대기·공지).
- xl 미만: 레일 → 하단 플로팅 내비. 한 열로 쌓이며 순서는 진행 중 → 배치 대기 → 최근 기록 → 공지.
- 페이지 높이는 고정하지 않고 스크롤.

### KPI — Stripe식 스트립
- 카드·제목 칸 제거. 배경 위 4칸(진행 중 · 완료 · 미완료 · 시간초과), 얇은 세로선 구분.
- 라벨 진하게, 숫자 34px, 아래 보조 한 줄(실시간 / 오늘 8건 중 / 어제 N건).
- 색은 미완료·시간초과 숫자에만.
- xl 미만도 4칸 한 줄 유지: lg 26px, md(≤760px) 22px, sm(≤520px) 20px + 보조 줄 숨김.
- 배치 숫자는 KPI에서 빼고 배치 대기 패널에만 둠(중복 제거).

### 진행 중인 순찰 (SSE 실시간)
- 동시 1~4건 가정, 2×2 카드. 5건 이상이면 행 추가. md 이하 1열.
- 지점은 상태색 칩(완료 초록 / 건너뜀 노랑 / 다음 파랑 테두리 / 대기 회색)으로 모든 이름 노출.
- 시간초과 카드는 테두리·시간 막대 빨강 + "+N분" 배지. 교대는 해당 지점 칩 안에 표시.
- "실시간" 표시는 이 섹션 제목 옆에만.

### 최근 기록
- 진행 중(개별 카드)과 구분되도록 흰 패널 하나 안에 두 목록(미완료·시간초과 | 종료된 순찰)을 세로선으로 나눔.
- xl 미만은 숫자 배지가 붙은 탭으로 전환.
- 미완료는 순찰 1건 = 1행, 놓친 지점 이름 포함. 종료된 순찰은 "완료" 배지 대신 미니 진행 막대 + 인증 수.

### 배치 대기 패널
- 배치 요청 / 복귀 요청 그룹, 요청마다 "N일 대기"와 반려·승인 버튼.

## 4. 레퍼런스 조사 요약 (KPI·대시보드)
- 운영 대시보드는 "지금 무엇에 손을 써야 하나"에 답해야 하며 예외를 먼저 노출.
- 색은 처리가 필요한 곳에만, 나머지는 중립.
- KPI 숫자에는 비교 대상(목표·전일)과 다음 행동(클릭 시 상세)이 필요.
- 지표는 2~3개 묶음으로 보여야 덩어리로 읽힘.
- 모바일은 확인용: 한 열, 핵심 지표 위주.
- 탭은 숨은 쪽을 놓치기 쉬우므로 숫자 배지 필수.
- Stripe·Plausible: 카드 없이 큰 숫자 + 작은 비교 텍스트, 여백을 적극 활용.
- 순찰 솔루션(OnPatrol, TrackTik)도 진행 중 / 이력 분리 + 실시간 대시보드 구성.

## 5. 확인 필요 사항
- 오늘 예정 순찰 수(완료 "8건 중"의 분모) 서버 제공 여부.
- KPI 보조 줄 "어제 N건" 데이터 제공 여부(시안은 가짜 값).
- 배치 요청 대기 일수, 복귀 요청 데이터(시안은 가짜 값).
- 코스/지점의 소속 코스 수를 링크로 쓸지 여부.
