# 디자인 규칙 (목업 A 컨셉 · Slate + Blue)

목업 7장(대시보드 · 배치관리 · 코스 상세 · 지점 상세 · 근무자 목록 · 근무자 추가 모달 · 코스 순찰이력)에서
실제로 쓴 값을 모은 것이다. **확정**은 사용자가 고른 것, **임시**는 목업에서 눈대중으로 둔 것,
**문제**는 고쳐야 하는 것이다. 정리일 2026-11-19.

## 3. 글자

글꼴은 **Noto Sans KR**(확정 2026-11-19 — Pretendard 에서 바꿈). 숫자는 모두 고정폭 숫자(`tabular-nums`).

바꾼 이유 — Pretendard 는 작은 크기에서 획을 화소에 맞추는 보정이 없어 100% 배율 Windows 화면에서 한글 윗부분 가로획이 흐리게 보인다(13px 표 글자에서 확인). 줄 폭은 거의 같다(같은 문장 13px 기준 Pretendard 404px · Noto Sans KR 409px). 실제 적용 때는 글꼴 파일을 서비스에 포함해 배포할지 확인한다(외부 접속이 막힌 망에서는 구글 서버에서 받지 못한다).

## 5. 상태 표시

**아이콘 + 글자.** 색은 아이콘에만 넣고 글자는 검정. 문제(빨강)일 때만 글자도 색. 색 세로 띠 · 옅은 뱃지는 쓰지 않는다.
아이콘 13px, 글자 12px, 간격 5px.

| 상태 | 아이콘 | 색 | 상태 |
|---|---|---|---|
| 진행중 · 순찰 중 | 한쪽이 열린 고리 | 파랑 | 확정 |
| 완료 · 인증 · 사용 · 배치 중 | 체크 원 | 초록 | 확정 |
| 근무 중 | 점이 든 원 | 초록 | 임시 |
| 미완료 · 미인증 · 근무 종료 · 복귀 완료 | 빼기 원 | 회색 | 확정(완료와 색 · 모양 둘 다로 구분) |
| 시간초과 | 시계 | 빨강(글자도) | 확정 |
| 반려 | X 원 | 빨강(글자도) | 임시 |
| 특이사항 | 빈 말풍선 | 진한 회색(sub) | 확정 |
| 교대 | 좌우 화살표 + `교대` | 파랑 | 임시 |

- 한 줄에 상태가 둘이면 나란히 놓는다(`완료` `시간초과`). 하나로 합치지 않는다.
- 목록에서는 관련 칸에 붙인다 — 시간초과는 소요 칸(빨간 시계 + 시간), 교대는 순찰자 칸, 특이사항은 칸 없이 순찰 결과 옆 말풍선(마우스를 올리면 `특이사항 있음`).
- 권한은 상태가 아니라 분류다 — 아이콘 없이 글자만, `현장 관리자`만 옅은 상자.

아직 아이콘을 정하지 않은 상태: 대기중 · 순찰제외 · 배치 요청 · 복귀 요청의 처리 상태 전부.

| 화면 제목 오른쪽 버튼 | 테두리 없이 옅은 회색 채움(`#f1f5f9`, 올리면 `#e2e8f0`) — 이동(`코스 상세` · `지점 상세`) · 더보기(`…`) · `수정`. `삭제`는 옅은 빨강 채움(`#fef2f2`) + 빨간 글자. 목록의 필터 · 검색 옆 버튼은 검색 칸과 같은 테두리 유지 | 확정(2026-11-20) |
| 모달 | 본문 위 어두운 막 + 흰 상자(모서리 12px · 그림자). 제목 · 설명 · 닫기 → 입력 칸 → 가로 전체 폭 버튼 | 확정 |
| 입력 칸 | 이름표는 위. 필수는 빨간 `*`. 포커스는 파란 테두리 + 옅은 파란 번짐. 비활성은 회색 바탕 | 임시 |
