# 추가 요소 기록

목업에는 있지만 **지금 구현된 화면에는 없는 것**들. 기본 내용은 지금 구현을 따르고,
아래는 필요한지 판단한 뒤에 따로 작업한다(사용자 결정 2026-11-19).

2026-11-19 코드와 대조했다 — 응답 타입(`features/*/types`)과 화면 구성 요소를 읽고 확인한 것이다.
서버를 직접 호출해 값을 본 것은 아니다. **추천**은 Claude 의견이고 **판단**은 사용자가 정한다.

구분: **표시만** = 응답에 값이 있어 그리기만 하면 됨 / **계산** = 받은 값으로 계산 / **요청** = 백엔드에 새 값이 필요 / **근거 없음** = 값이 없거나 뜻이 틀림
